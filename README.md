# Dart Code

Dart Code extends [VS Code](https://code.visualstudio.com/) with support for the [Dart](https://dart.dev/) programming language and [Flutter](https://flutter.dev/) apps.

- **Install**: [Dart extension on the Visual Studio Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Dart-Code.dart-code)
- **Issues**: [Report a bug or request a feature](https://github.com/Dart-Code/Dart-Code/issues/new/choose)

## Repository Layout

- `extensions/dart/` — Dart VS Code extension manifest, assets, snippets, syntax grammars, and source ([Dart Extension README](extensions/dart/README.md))
- `src/shared/` — Shared code used by extensions, debug adapters, and automated tests
- `src/test/` — Automated test suites and test projects
